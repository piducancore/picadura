# Picadura 0.3.0 — Unsigned preview

An original generative acid-line MIDI sequencer by piducancore.

## New in 0.3.0

- **Learn from MIDI or monophonic audio.** Send notes to Picadura or route a
  clean bass/melody loop through its input, choose **INPUT: MIDI** or
  **INPUT: Audio**, and press **LEARN**. The learned pitch-class pool appears
  beside the controls; **FREEZE** stops collecting and **CLEAR** starts a new
  pool. MIDI captures Note On events. Audio uses a fixed-buffer, confidence-
  gated YIN-style estimator (roughly 40–1200 Hz) and passes input through
  unchanged.
- **Influence** blends the selected scale with the learned pool from 0 to 100.
  **Strict** restricts generated and mutated pitches to learned pitch classes.
  **Follow Root** anchors the register on the most frequent learned pitch class.
  With no learned notes, generation falls back to the scale. Manual notes and
  locks always take priority.
- **Sixteen scales:** Minor (natural), Dorian, Phrygian, Major, Pentatonic
  (minor), Chromatic, Lydian, Mixolydian, Locrian, Harmonic Minor, Melodic Minor
  (ascending), Major Pentatonic, Blues (minor), Whole Tone, Diminished Whole–Half,
  and Diminished Half–Whole.
- **Movement** controls how strongly generated pitches repeat or stay near the
  previous scale degree. The default of 100 preserves the original contour.
- **Mutate** changes the pitch of a quarter (rounded up) of the currently
  sounding, unlocked steps across the active pattern. Rhythm, accents, slides,
  timing, rests and unselected steps stay unchanged.
- **Per-step locks (Held)** snapshot pitch, note/rest state, accent and slide.
  Locked steps survive generation and mutation; click Held to release the
  snapshot and resume the underlying step.
- The Slint editor is larger to fit the learning controls, and MIDI input is
  enabled for the plugin.

## Core sequencer

- Up to 64 steps across four pages.
- Vertical step dragging edits pitch; horizontal dragging shifts note triggers
  early/late by up to 25% of a sixteenth.
- Separate regeneration of notes, rhythm and expression.
- Root/scale selection, octave range, density, accents, gates, slides and swing.
- Native Slint interface styled alongside Buffer Uppercut.
- Host automation and session recall for notes, timing offsets, seeds, locks,
  movement, learning controls and the learned pitch pool.

## Packages

All ZIPs include VST3 and CLAP, installation instructions and license notices.

- macOS: Apple Silicon arm64, built on macos-15. Not an Intel/universal build.
- Windows: x86-64, built on windows-2022.
- Linux: x86-64, built on Ubuntu 22.04; glibc/X11/font/graphics libraries required.

Windows and Linux builds use Truce's default x86-64-v3 CPU target (AVX2-class CPUs).
These are unsigned previews; macOS bundles use ad-hoc signing, with no Developer ID or notarization.

## Validation and limitations

The release workflow runs formatting, Clippy, tests, allocation checks, CLAP
validation and pluginval strictness 5 on each platform before packaging. GUI
tests are skipped on hosted CI runners. The Slint interface and simulated
pitch/timing drags were tested locally on macOS.

MIDI routing was confirmed by the user in Ableton Live on macOS. Audio learning
uses synthesized monophonic signals in automated tests; routing a real loop
through a DAW still needs auditioning. Chords, drums, dense mixes, heavy
distortion and very short notes can be missed or misidentified. Learning tracks
pitch classes, not timing, exact octaves or chord changes. The exact
downloadable artifacts have not been auditioned in a DAW on all three platforms.
Windows and Linux DAW compatibility remains unverified.

Picadura generates MIDI only. In Live, route its output to an instrument on a
separate track. Slides require a synth with mono legato/portamento. A note
scheduled before the host starts cannot be played retroactively; negative
offsets on step one are heard on subsequent cycles. No built-in synth or
instrument hosting.
