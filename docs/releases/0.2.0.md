# Picadura 0.2.0 — Unsigned preview

An original generative acid-line MIDI sequencer by piducancore.

- Up to 64 steps across four pages.
- Vertical step dragging edits pitch; horizontal dragging shifts note triggers early/late by up to 25% of a sixteenth.
- Separate regeneration of notes, rhythm and expression.
- Root/scale selection, octave range, density, accents, gates, slides and swing.
- Native Slint interface styled alongside Buffer Uppercut.
- Host automation and session recall for notes, timing offsets and seeds.

## Packages

All ZIPs include VST3 and CLAP, installation instructions and license notices.

- macOS: Apple Silicon arm64, built on macos-15. Not an Intel/universal build.
- Windows: x86-64, built on windows-2022.
- Linux: x86-64, built on Ubuntu 22.04; glibc/X11/font/graphics libraries required.

Windows and Linux builds use Truce's default x86-64-v3 CPU target (AVX2-class CPUs).
These are unsigned previews; macOS bundles use ad-hoc signing, with no Developer ID or notarization.

## Validation and limitations

The release workflow runs tests, allocation checks, Clippy, CLAP validation and pluginval strictness 5 on each platform before packaging. GUI tests are skipped on hosted CI runners. The Slint interface was rendered and tested locally on macOS, including simulated pitch/timing drags.

Earlier MIDI routing was confirmed by the user in Ableton Live on macOS. The exact downloadable artifacts have not been auditioned in a DAW on all three platforms. Windows and Linux DAW compatibility remains unverified.

Picadura generates MIDI only. In Live, route its output to an instrument on a separate track. Slides require a synth with mono legato/portamento. A note scheduled before the host starts cannot be played retroactively; negative offsets on step one are heard on subsequent cycles. No built-in synth or instrument hosting.
